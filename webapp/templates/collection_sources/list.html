        Newsletter imports (e.g. the ETDA CTI Robot importer)
        publish the selected article URLs to the misp-scraper's Redis channel. The scraper then fetches each
        article and creates the MISP event, so they behave like normal scraper events. The scraper's
        subscribe service must be running against this Redis.

{# ── IMAP mailboxes ───────────────────────────────────────────────────── #}


  

    IMAP mailboxes
    
  

  

    

      Poll a mailbox for forwarded e-mails. A mailbox holds one or more data collection sources;
      each new message is matched to the first source whose subject or sender criteria fit, then parsed,
      archived in MISP and (in automatic mode) pushed to the scraper. Polling is run by
      run_imap_collector.py from cron. Items awaiting review appear under
      Email sources.
