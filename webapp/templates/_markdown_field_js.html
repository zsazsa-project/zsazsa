{# The Markdown field. Every textarea[data-markdown] on the page gets a slim bar with Write, Preview and Side by side, and Ctrl+B and Ctrl+I (Cmd on a Mac) for bold and italic, as GitHub's comment box has. Every field opens in Write. The textarea stays the form field, so what is saved is what the analyst typed. A page that adds a textarea later calls zsazsaMarkdownField(textarea) on it, and one that sets a field's text from a script calls zsazsaRefreshMarkdown(textarea), since that fires no input event. zsazsaInsertAfter(node, text) puts text into the field after the block of its preview that node is in, as the indicator lookup does with an answer. #} {% include "_markdown_js.html" %}
